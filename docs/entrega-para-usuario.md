# Entrega de primeira sessão

Entregar somente `FoisonC24-Cliente-Win7-x64.zip`, com instalador completo,
instruções portuguesas, quadrado de referência e checksum. Não entregar fontes
ou scripts como tarefa técnica para o cliente: engines/fontes/pré-requisitos
já são incluídos pelo instalador.

O cliente instala acompanhado, imprime pelo Corel e segue confirmações. O
roteiro técnico é responsabilidade do desenvolvedor e está em
[PRIMEIRA-SESSAO](../packaging/windows/PRIMEIRA-SESSAO.md).
Não prometer corte: Win7/Corel/revisão/protocolo/área/serial físicos ainda precisam
passar os portões na sessão. Se faltar evidência, bloquear e preservar FlexiSIGN.
