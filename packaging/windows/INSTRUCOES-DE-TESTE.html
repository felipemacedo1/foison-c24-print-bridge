Foison C24 Print Bridge

Importante: esta distribuição ainda não é instalável. A fila do Windows 7 e o receptor Windows não foram validados.

Quando a versão de teste estiver pronta

  1. Feche o FlexiSIGN.
  2. Execute o instalador como administrador.
  3. Abra o CorelDRAW X6 e desenhe um quadrado de 50 x 50 mm.
  4. Use Arquivo → Imprimir e selecione Foison C24 (Teste).
  5. Imprima em modo simulação. A plotter não deve se mover.
  6. Abra o Bridge, clique em Exportar diagnóstico e envie o arquivo.

Não faça

  • Não instale Python, Git ou drivers encontrados na internet.
  • Não altere o registro, o spooler, o FlexiSIGN ou o driver FTDI.
  • Não tente usar a COM2 nesta primeira etapa.
