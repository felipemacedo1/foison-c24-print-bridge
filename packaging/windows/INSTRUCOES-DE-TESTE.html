Foison C24 Print Bridge

Importante: este é um candidato experimental instalável, mas ainda não foi validado em Windows 7 real. Ele nunca envia dados à COM2.

Como testar

  1. Baixe e extraia o ZIP. Execute FoisonC24-Teste-Setup-x64.exe como administrador.
  2. Não remova nem altere filas existentes. Se já existir uma fila com esse nome, o instalador abortará e preservará a configuração.
  3. Abra o CorelDRAW X6 e desenhe um quadrado de 50 x 50 mm.
  4. Use Arquivo → Imprimir e selecione Foison C24 (Teste).
  5. Imprima. A plotter deve permanecer desligada e não deve se mover.
  6. Abra Foison C24 Diagnóstico, clique em Exportar diagnóstico e envie o arquivo ao desenvolvedor.

Não faça

  • Não instale Python, Git ou drivers encontrados na internet.
  • Não altere o registro, o spooler, o FlexiSIGN ou o driver FTDI.
  • Não tente usar a COM2 nesta primeira etapa.
